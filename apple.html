Skills de Claude

Skills que ensenyen a Claude a fer tasques concretes.

Les integrades ja venen amb Claude, els plugins s'instal·len des del directori de plugins i les de GitHub es copien a la carpeta del projecte. Toca una skill per veure com s'obté.

Vols més skills? En trobaràs al directori de plugins de claude.ai i a GitHub. Abans d'instal·lar-ne una, mira'n la llicència i si demana compte o pagament. També pots veure aquest catàleg a la versió Bauhaus.
